gemini-app-scaler

1. Data Collection
This extension collects zero user data.

Your prompts, responses, and conversations on Google Gemini are never read, accessed, collected, or transmitted.

There is no telemetry, tracking, or analytics software included in this extension.

No external scripts are loaded.

2. Permissions Used
To function properly, this extension requires the following permissions, which are strictly used for local features:

storage: This is required to save your user-defined layout parameters (like your preferred width unit, width values, density settings, and toggle states). These settings are saved to chrome.storage.sync so your preferences persist across your browsing sessions and synced Chrome profiles. No personal data is stored.

Host Permission (*://[gemini.google.com/](https://gemini.google.com/)*): This is required to authorize the extension's content script to inject the overriding CSS stylesheets. This permission is strictly limited to the Gemini web application and cannot interact with any other websites you visit.

3. Changes to this Policy
If any future updates to the extension require changes to how data or permissions are handled, this Privacy Policy will be updated accordingly.
