# Gemini Layout Optimizer

A lightweight Chrome Extension that modifies the visual layout, container widths, and text density of the Google Gemini web application to improve readability and screen utilization.

## Features
* **Width Scaling:** Set fixed pixel or responsive percentage container widths.
* **Custom Presets:** Save layout configurations for quick switching.
* **Density Controls:** Adjust line height and paragraph spacing.
* **Code Wrapping:** Auto-wrap code blocks to eliminate horizontal scrolling.

## Privacy
This extension operates strictly locally via CSS injection and collects zero user data.
